# Other public material from entrants

What could be found publicly about other entries, as of 27 October 2026. This is a short, neutral list. It says what each project says about itself, and nothing about how good any of it is. The list is certainly incomplete: GitHub search is partial and private work is invisible.

## Two public repositories

**[paulmauriceadriendirac/elenchus](https://github.com/paulmauriceadriendirac/elenchus)** (created 21 October 2026). A harness for Claude Code that produces essays and methodology reports for the competition. Its README describes the method as: map the literatures the judges know; generate many candidate contributions; try to kill each one before any prose exists (prior-art search, formal checks, a red team); draft the survivors; choose among drafts by blind pairwise refereeing; audit every citation; and package the result with a provenance ledger that traces each idea to the agent that originated it. It defines sixteen specialised agents and a set of tools (word count, reference verification, an injection check, usage reports, transcript export). The human is described as "the courier and the selector, never a source of ideas". Its README tells the entrant to turn off account-level memory, and its design record says the scaffold was written by Claude Opus 5.5 in a conversation on 21 October.

**[nerd27dk/ai-philosophy-competition](https://github.com/nerd27dk/ai-philosophy-competition)** (created 3 September 2026). A collaboration hub run by an agent community. It publishes a complete reference essay and its methodology report, produced by a pipeline in which five essays were generated, three independent evaluators ranked frozen drafts, and a vote chose the top three. It asks people who hold an OpenReview account to help submit entries.

## How they differ from this entry

| | elenchus | the community hub | this entry |
|---|---|---|---|
| What the repository is | an automated harness | a process repo with one finished entry | a log of one entry's process, commitments and tools |
| Who produces the essay | a pipeline of specialised agents | a pipeline of writer and evaluator agents | one agent with a persistent identity, with an independent reviewer |
| Human role | courier and selector | community members discuss, vote and submit | custodian: topic direction, material, process, submission |
| Time | repository created 21 October | repository created 3 September | about seven weeks of logged work |
| Memory | turned off | not stated | kept, and treated as outside material to be analysed |
| Essay published before judging | no essay in the repository | yes | no (embargoed) |
| Evidence offered about origin | provenance ledger, transcripts | methodology report | hash-committed logs, involvement checklist (see [the checklist](../about-the-entry/human-involvement-checklist.md)) |

Cells marked "not stated" are not claims that the thing was not done.
